# cubebridge

ESP32 / ESP32-S3 智能魔方蓝牙网关：连接实体智能魔方（魔域 MHC、魔域 WCU_MY3、奇艺 QY-QYSC），将转动、状态和电量转换为 GAN Gen2 协议，供支持该协议的手机 App 使用。

## 下载固件与准备硬件

根据开发板的芯片型号下载对应固件。两份固件均基于 main 的 `58b6989` 版本，使用 ESP-IDF 6.0.1 构建。

| 开发板 | Flash 容量 | 固件下载 | 板载状态灯 |
| --- | --- | --- | --- |
| 普通 ESP32（如 ESP32-WROOM-32 / DevKitC） | 4 MB | [cubebridge_esp32_20261002.bin](release/cubebridge_esp32_20261002.bin) | GPIO2 单色 LED |
| ESP32-S3（如 N16R8 开发板） | 16 MB | [cubebridge_esp32s3_20260929.bin](release/cubebridge_esp32s3_20260929.bin) | GPIO48 WS2812 RGB LED |

**两种固件不能混用。** ESP32 固件不适用于 ESP32-S2、ESP32-S3、ESP32-C3 等其他芯片；S3 固件要求 16 MB Flash。下载前请核对开发板型号与容量。状态灯引脚不同的开发板可能无法显示下文的灯光提示。

还需要：

- 一根 USB **数据线**，纯充电线不能用于烧录。
- 一台电脑，安装支持 Web Serial 的 Chrome 或 Edge 浏览器；请使用电脑端浏览器，Safari / Firefox 不支持本教程的烧录方式。
- 一只支持的智能魔方和支持 GAN Gen2 协议的手机 App。

在 GitHub 中打开 `.bin` 文件后，点击 **Download raw file** 下载原始文件。下载后可使用 [SHA256SUMS](release/SHA256SUMS) 核对文件完整性。

## 用网页工具烧录

固件已经合并 bootloader、分区表和应用，用户无需安装开发环境，只需烧录对应的一份 `.bin`。**本仓库两份合并固件的烧录地址都填写 `0x0`**，普通 ESP32 也使用这个地址。

重新烧录这两份合并固件会覆盖保存配对记录的区域；完成后需要重新连接实体魔方。点击 **Erase** 会擦除开发板的整个 Flash，包括原有程序和数据。

1. **连接开发板。** 用 USB 数据线连接电脑。如果开发板有标为 **USB** 和 **COM / UART** 的两个接口，优先插 **COM / UART**；只有一个接口时使用该接口。关闭占用该串口的串口助手、监视器或其他烧录程序。
2. **打开工具。** 用 Chrome / Edge 打开 [ESP Web Tool](https://esptool.spacehuhn.com/)。
3. **连接串口。** 点击 **Connect**，在浏览器弹出的串口列表中选择开发板，然后点击连接。串口名称可能包含 `USB-SERIAL`、`CP210x`、`CH340`、`USBmodem` 或 `USB JTAG`。等待网页识别芯片，并核对识别结果与所选固件一致。
4. **选择固件。** 在文件列表中选择下载好的 `.bin`；如果列表为空，点击 **Add** 添加文件行，再选择文件。只保留对应开发板的一份合并固件。
5. **填写地址。** 将该文件行的烧录地址（Offset / Address）设为 **`0x0`**。不要填写应用分区地址 `0x10000`。
6. **开始烧录。** 点击 **Program**，如出现确认窗口则确认。等待进度结束并显示完成提示；烧录过程中保持供电，不拔线、不关闭网页。
7. **启动程序。** 松开 BOOT，按一下开发板上的 **RST / EN** 复位键。若开发板没有复位键，可断开 USB 后重新连接。

## 烧录后如何使用

1. 给开发板供电，唤醒实体魔方（通常转动一下即可），将魔方放在开发板附近。首次连接时，附近尽量只唤醒一只支持的魔方，避免设备连接到其他魔方。
2. 网关会自动扫描、连接并同步实体魔方。正常运行后，ESP32-S3 的状态灯为绿色微光短闪，普通 ESP32 的单色灯常亮。
3. 在手机 App 的魔方连接页面搜索并连接 **`GAN356iCarry`**。网关完成实体魔方状态同步后才会广播该名称；尚在扫描时，App 中可能找不到它。
4. 转动实体魔方，检查 App 中的转动与状态是否同步。已保存的魔方在下次启动时会被优先重连。

BOOT 按键的操作需在程序正常运行时进行：

- **短按（小于 1 秒）**：强制重新扫描实体魔方。
- **长按（至少 3 秒）**：清除保存的配对记录并重新扫描；S3 用红色三短闪确认，普通 ESP32 用单色三短闪确认。
- **RST / EN**：重启设备。正常使用按键时，无需同时按 BOOT 和 RST；该组合用于下文的下载模式。

状态灯含义如下。S3 的灯光亮度较低，扫描和运行时每次仅短暂点亮。

| 状态 | ESP32-S3（GPIO48 RGB） | ESP32（GPIO2 单色） |
| --- | --- | --- |
| 正在扫描实体魔方 | 蓝色慢闪 | 慢闪 |
| 正在连接 | 黄色快闪 | 快闪 |
| 正在同步状态 | 紫色闪烁 | 中速闪烁 |
| 正常运行 | 绿色微光短闪 | 常亮 |
| 断线重连 | 橙色快闪 | 较快闪烁 |
| 清除配对确认 | 红色三短闪 | 三短闪 |

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 串口列表为空 | 确认使用 USB 数据线，换线或换电脑 USB 口；双接口板优先使用 COM / UART。Windows 如缺少驱动，请按板载 USB 转串口芯片型号，从芯片厂商官网安装 CH340 / CH343 或 CP210x 驱动后重插。 |
| 串口连接失败或提示被占用 | 关闭串口助手、开发环境的串口监视器及其他占用设备的网页，然后重新 Connect。 |
| 连接超时，无法进入烧录 | 手动进入下载模式：**按住 BOOT → 短按 RST / EN → 松开 BOOT**，再重新 Connect。部分设备进入下载模式后串口会变化，需要重新选择。 |
| 烧录中途失败 | 更换数据线或 USB 口。在工具中断开连接，打开设置，将 **Baud Rate** 降为 **115200**，重新连接后再点 Program。 |
| 烧录完成但程序没有运行 | 松开 BOOT 后按 RST / EN，检查所选固件与芯片型号、Flash 容量是否一致，并确认合并固件地址是 `0x0`。 |
| 状态灯不亮 | 确认板载 LED 类型与引脚符合上表。S3 灯光很暗且亮起时间短，可在较暗环境观察；其他引脚的板载灯不作为本固件的启动判断依据。 |
| 一直扫描，或手机找不到虚拟魔方 | 唤醒支持的实体魔方，将其放近开发板，并断开其他 App 对该实体魔方的连接。待实体魔方完成同步后，再在手机 App 中搜索 `GAN356iCarry`。 |
| 想更换实体魔方 | 正常运行时长按 BOOT 至少 3 秒清除旧配对，唤醒目标魔方并等待重新连接。 |
| 想完全清除旧程序与数据 | 在网页连接设备后点击 **Erase** 并确认，等待擦除完成，再按上述步骤 Program；所有 Flash 数据都会被删除。 |

## 自行编译

需要 ESP-IDF 6.0.1。按开发板选择目标，再编译与烧录：

```sh
idf.py set-target esp32s3   # 普通 ESP32 改为 esp32
idf.py build flash monitor
```

上述发布固件的分区布局为：NVS `0x9000`、PHY `0xf000`、factory 应用 `0x10000`，应用分区容量 1 MiB，无 OTA。两份固件均采用 main 的默认构建配置，未开启 `CONFIG_VCUBE_TEST_INPUT`。

串口速率为 115200，可用 `state` / `?` 查看当前状态，`help` 查看帮助。开发者开启 `CONFIG_VCUBE_TEST_INPUT` 后可使用 UART 转动命令和六路 GPIO 离线测试输入；这些输入不经 BLE 转发，实体魔方在线时自动禁用。

| 离线测试按键 | GPIO |
| --- | --- |
| ESP32 | 32、33、25、26、27、14 |
| ESP32-S3 | 4、5、6、7、15、16 |
